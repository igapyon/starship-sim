# Starship Sim 🧪

⚠️ **EXPERIMENTAL PROJECT**

2次元宇宙空間における**基本ユニット（艦船）の仕様設計**プロジェクト。物理エンジンとAI戦闘ロジックの実験的実装により、シミュレーション内で統一された動作仕様を持つユニットを実現しています。ブラウザで動作します。

## 概要

このプロジェクトは、シミュレーション内における基本的なユニット（艦船）の統一仕様を定める実験です。白色のプレイヤー艦とシアン色の敵艦4体が、同じ物理法則と戦闘ルールに従いながら宇宙空間で戦闘します。プレイヤーはマウス/タッチで目標位置を指定し、システムが自動的に操舵・射撃を行います。敵艦も同じロジックに従い、索敵範囲内でのみプレイヤーを認識し追跡します。物理演算に基づいた慣性のある動きと、画面端での斥力システムにより、統一されたユニット仕様のリアルな挙動を実現しています。

## 特徴

- **統一されたユニット仕様**: プレイヤー艦と敵艦が同じ物理法則と戦闘ルールに従う
- **物理ベースの動き**: 艦の加速・減速に慣性が反映される
- **自動戦闘AI**: 敵艦が索敵範囲内でプレイヤーを追跡し、目標が前方15度以内の時のみ射撃
- **プレイヤー操作**: マウス/タッチで目標位置を指定し、敵艦を自動選択
- **画面端の斥力**: 艦が画面端に近づくほど強い斥力が働く
- **リアルタイム情報表示**: 位置、速度、角度、HP などをリアルタイム表示
- **色分けされた弾**: プレイヤー弾は黄色、敵弾はマゼンタ
- **爆発エフェクト**: 艦が破壊されるとパーティクルエフェクトが発生

## 使い方

1. `index.html` をブラウザで開く
2. 画面上をマウス/タッチして目標位置を指定します
3. プレイヤー艦が自動的に操舵・加速し、目標を追跡します
4. 敵艦が索敵範囲内に入るとプレイヤーが自動的に敵を目標に切り替えます
5. 右下の「スラスタ」ボタンでエンジン推進力のON/OFFを切り替えられます

## ゲーム要素

### 艦

- **白色（プレイヤー艦）**: マウス/タッチ位置またはマウス位置の敵艦を目指して移動・射撃
- **シアン色（敵艦）**: 索敵範囲内のプレイヤー艦を認識して追跡・射撃（4体、画面の四隅に配置）

### 弾

- **黄色**: プレイヤー艦が発射
- **マゼンタ**: 敵艦が発射
- 300フレーム後、または画面外に出たら消滅

### 情報表示

画面左上に以下の情報がリアルタイム表示されます：
- 位置（x, y 座標）
- 速度（u/frame 単位）
- 角度（度数法）
- HP（プレイヤー艦）
- 敵艦数
- 弾数

## 仕様

### 物理パラメータ

- **艦のサイズ**: 12 ピクセル
- **最高速度**: 2 u/frame
- **回転速度**: 0.05 rad/frame
- **スラスタ出力**: 0.05 u/frame²
- **推力調整**: 目標方向との角度差に応じて 0～100% に調整
- **摩擦**: 毎フレーム速度の 2% を減速

### 戦闘パラメータ

- **艦の初期HP**: 100
- **プレイヤーへのダメージ**: 敵弾 1 発につき 10
- **敵艦へのダメージ**: プレイヤー弾 1 発につき 25
- **射撃間隔**: 60フレーム
- **射撃可能範囲**: 前方 15 度以内
- **索敵範囲**: 150 ピクセル（敵艦はこの範囲内のみプレイヤーを認識）
- **弾の最大射程**: 索敵範囲の 1.5 倍

### 画面端の物理

- **斥力範囲**: 画面端から 80 ピクセル
- **最大斥力**: 0.05 u/frame²
- **敵艦の目標修正**: 画面端近くで中央方向に 60% 修正

## 技術仕様

- **言語**: JavaScript (ES6)
- **グラフィックス**: HTML5 Canvas
- **フレームレート**: requestAnimationFrame（ブラウザ依存）
- **依存関係**: なし（素の JavaScript のみ）
