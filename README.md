# Starship Sim 🧪

⚠️ **EXPERIMENTAL PROJECT**

2次元宇宙空間での自動戦闘シミュレーション。物理エンジンとAI戦闘ロジックの実験的実装です。ブラウザで動作します。

## 概要

白色のプレイヤー艦とシアン色の敵艦が宇宙空間で自動的に戦闘するシミュレーションです。両艦は相互に追跡し、自動で射撃します。物理演算に基づいた慣性のある動きと、画面端での斥力システムにより、リアルな宇宙戦闘の雰囲気を演出しています。

## 特徴

- **物理ベースの動き**: 艦の加速・減速に慣性が反映される
- **自動戦闘AI**: 両艦が相互に追跡し、目標が前方にある時のみ射撃
- **画面端の斥力**: 艦が画面端に近づくほど強い斥力が働く
- **リアルタイム情報表示**: 位置、速度、角度、HP などをリアルタイム表示
- **色分けされた弾**: プレイヤー弾は黄色、敵弾はマゼンタ

## 使い方

1. `starship_sim.html` をブラウザで開く
2. シミュレーションが自動的に開始されます
3. 画面上で白色の艦（プレイヤー）とシアン色の艦（敵）が戦闘します

## ゲーム要素

### 艦

- **白色（プレイヤー艦）**: 敵艦を目指して移動・射撃
- **シアン色（敵艦）**: プレイヤー艦を追跡・射撃

### 弾

- **黄色**: プレイヤー艦が発射
- **マゼンタ**: 敵艦が発射
- 300フレーム後、または画面外に出たら消滅

### 情報表示

画面左上に以下の情報が表示されます：
- 位置（x, y 座標）
- 速度（u/frame 単位）
- 角度（度数法）
- スラスタ状態（ON/OFF）
- HP（プレイヤー艦）
- 敵艦数
- 弾数

## 仕様

### 物理パラメータ

- **艦のサイズ**: 12 ピクセル
- **最高速度**: 2 u/frame
- **回転速度**: 0.02 rad/frame (方向転換は推進力に応じて減衰)
- **スラスタ出力**: 0.05 u/frame²
- **推力調整**: 目標方向との角度差に応じて 0～100% に調整
- **摩擦**: 毎フレーム速度の 2% を減速

### 戦闘パラメータ

- **艦の初期HP**: 100
- **プレイヤーへのダメージ**: 敵弾 1 発につき 10
- **敵艦へのダメージ**: プレイヤー弾 1 発につき 25
- **射撃間隔**: 60フレーム
- **射撃可能範囲**: 前方 15 度以内（高精度射撃）

### 画面端の物理

- **斥力範囲**: 画面端から 80 ピクセル
- **最大斥力**: 0.05 u/frame²
- **敵艦の目標修正**: 画面端近くで中央方向に 60% 修正

## 技術仕様

- **言語**: JavaScript (ES6)
- **グラフィックス**: HTML5 Canvas
- **フレームレート**: requestAnimationFrame（ブラウザ依存）
- **依存関係**: なし（素の JavaScript のみ）
